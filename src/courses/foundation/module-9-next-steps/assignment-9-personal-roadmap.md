# Final Assessment: Your Personal Learning Roadmap

This is the most important assignment in the course. You are going to design your own curriculum for the next 3-6 months.

## The Goal

Create a concrete plan that takes you from "Foundation Graduate" to "Job Ready" (or whatever your personal goal is).

## The Output

Create a document (Markdown, Google Doc, or handwritten) that includes the following four sections:

### 1. The Destination (Goal)

Be specific.

- **Bad:** "I want to code."
- **Good:** "I want to get a job as a Junior React Developer in my city by December."
- **Good:** "I want to build a mobile app for my specialized dog walking business."

### 2. The Path (Tech Stack)

Based on your goal, what languages/tools do you need?

- _Example:_ HTML -> CSS -> JavaScript -> React -> Firebase.

### 3. The Timeline (Milestones)

Break your path into months.

- **Month 1:** Focus on Advanced JavaScript (ES6, Arrays, Objects).
- **Month 2:** Learn the basics of React (Components, State).
- **Month 3:** Build a portfolio project (Weather App).

### 4. The Capstone Project Idea

Think of ONE major project that would impress you.

- It should be slightly too hard for you right now.
- It should solve a real problem you have.

## Grading Checklist (Self-Check)

- [ ] Is your goal specific and time-bound?
- [ ] Is your chosen stack relevant to your goal?
- [ ] Is your timeline realistic? (Did you account for rest/life?)

## Submission

Save this document. Print it out. Stick it on your wall. This is your map for the wilderness ahead.
