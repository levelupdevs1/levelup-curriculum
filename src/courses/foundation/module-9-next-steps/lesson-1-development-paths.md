# Overview of Development Paths

One of the most exciting (and overwhelming) parts of finishing the basics is realizing how many directions you can go. Software development is not one single job; it is a massive industry with many specializations.

Here are the most common paths you can choose from.

## 1. Web Development

Building websites and applications that run in a browser. This is the most common entry point for new developers.

- **Frontend:** You build what users see.
  - _Tech Stack:_ HTML, CSS, JavaScript, React, Vue.
- **Backend:** You build the servers, databases, and logic that powers the frontend.
  - _Tech Stack:_ Node.js, Python, Ruby, Go, SQL.
- **Full Stack:** You do both. You can build a complete product from start to finish.

## 2. Mobile Development

Building apps for smartphones.

- **Native iOS:** Building specificly for iPhone/iPad.
  - _Language:_ Swift.
- **Native Android:** Building specifically for Android phones.
  - _Language:_ Kotlin or Java.
- **Cross-Platform:** Writing one code base that runs on both.
  - _Tech Stack:_ React Native, Flutter.

## 3. Data Science & AI

Using code to analyze data, find patterns, or build intelligent systems.

- **Data Analyst:** Making sense of numbers (Excel, SQL, Python).
- **Machine Learning Engineer:** Teaching computers to recognize patterns.
  - _Tech Stack:_ Python (libraries like Pandas, TensorFlow, PyTorch).

## 4. Game Development

Building video games for consoles, PC, or mobile.

- _Tech Stack:_ C++, C# (Unity), Unreal Engine.
- _Note:_ This field serves distinct challenges regarding physics and 3D math.

## 5. DevOps & Cloud

Focusing on _how_ software is delivered and kept running.

- You don't write the app features; you build the "pipelines" that get the code from a laptop to a massive server.
- _Tech Stack:_ AWS, Docker, Kubernetes, Linux.

## Use the Foundation

The good news is that the **foundation you just learned applies to ALL of these**.

- Every path uses variables, loops, and logic.
- Every path uses Git.
- Every path requires problem-solving.
