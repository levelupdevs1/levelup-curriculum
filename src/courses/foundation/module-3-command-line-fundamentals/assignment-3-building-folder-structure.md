# Assessment: Build a Folder Structure

It is time to put your new skills to the test. In this assignment, you will create a complete project structure using _only_ the command line.

**No mouse allowed!** 🚫🖱️

## The Goal

You need to create the following structure for a photography portfolio site:

```
portfolio/
├── images/
├── css/
│   └── style.css
├── index.html
└── about.html
```

## Instructions

1. Open your terminal.
2. Navigate to your Desktop (hint: `cd ~/Desktop`).
3. Create a main folder named `portfolio`.
4. Go into that folder.
5. Create two sub-folders: `images` and `css`.
6. Create empty files: `index.html` and `about.html`.
7. Go into the `css` folder.
8. Create a file named `style.css`.
9. Go back to the main `portfolio` folder.
10. Run `ls -R` (if on Mac/Linux) or `tree` (if installed) or just explore with `cd` and `ls` to verify everything is there.

## Bonus Challenge (Optional)

1. Create a file named `temp.txt`.
2. Rename it to `notes.txt`.
3. Delete it.

## Checklist

- [ ] Folder `portfolio` exists
- [ ] Folders `images` and `css` exist inside it
- [ ] Files `index.html` and `about.html` exist in `portfolio`
- [ ] File `style.css` exists in `css`
- [ ] You did it all without clicking a single folder icon!
