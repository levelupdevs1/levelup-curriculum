# Command line tips and shortcuts

You don't need to type fast to be efficient. You just need to know the shortcuts. These tricks will make you look like a pro.

## 1. Up Arrow (History)

Don't type the same long command twice.
Press the **Up Arrow** key to scroll through your previous commands.

## 2. Tab Completion (The Magic Key)

Never type a full filename again.
If you have a file named `really-long-file-name.txt`, just type:
`real` and hit **TAB**.
The terminal will type the rest for you. If it stops, there might be multiple files starting with that name—press TAB twice to see options.

## 3. Clear the screen

If your screen is messy, type:

```bash
clear
```

(Or use `Ctrl + L` / `Command + K` on Mac).

## 4. Get me out of here! (`Ctrl + C`)

If a command is stuck, running forever, or you just want to cancel what you are typing for a fresh line:
Press **`Ctrl + C`**.
This sends an "Interrupt" signal to stop the current process.

## 5. Copy and Paste

In many terminals, `Ctrl + C` is for stopping commands (see above). So you can't use it to copy text!

- **Windows (Git Bash/PowerShell):** Right-click usually pastes. `Ctrl + Insert` copies, `Shift + Insert` pastes.
- **Mac:** standard `Command + C` / `Command + V` usually works.
- **Linux:** `Ctrl + Shift + C` / `Ctrl + Shift + V`.
