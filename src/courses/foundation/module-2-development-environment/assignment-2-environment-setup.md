# Assessment: Development Environment Setup

Complete the following tasks to finish Module 2.

## Task 1: Install your code editor

- Install Visual Studio Code on your computer  
- Open VS Code and explore the welcome screen  

## Task 2: Install helpful extensions

Install at least these extensions in VS Code:

- Prettier  
- Live Server  
- One theme of your choice  

## Task 3: Create a project folder

Using the terminal in VS Code:

1. Open the terminal  
2. Navigate to a directory where you want to store projects  
3. Run this command:

```bash
mkdir my-first-project
```

4. Move into the folder:

```bash
cd my-first-project
```

5. Create the following structure:

```text
my-first-project/
  index.html
  styles/
  scripts/
```

For example:

```bash
mkdir styles
mkdir scripts
touch index.html
```

On Windows, use:

```bash
type nul > index.html
```

## Task 4: Take a screenshot

Take a screenshot that shows:

- VS Code open  
- The Explorer panel with your folder structure  
- The terminal at the bottom with some of the commands you used  

This confirms that your environment is ready for the rest of the course.
