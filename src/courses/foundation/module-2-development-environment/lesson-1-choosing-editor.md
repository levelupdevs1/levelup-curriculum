# Choosing and Installing a Code Editor

A code editor is the main tool you will use to write and manage code. It is similar to a text editor, but designed specifically for programming. It helps you write cleaner code, catch errors early, and stay organized.

There are many code editors available, but Visual Studio Code, also called VS Code, is one of the best choices for beginners and professionals.

## Why beginners should use VS Code

- It is free  
- It works on Windows, macOS, and Linux  
- It supports many programming languages out of the box  
- It has thousands of helpful extensions  
- It is friendly for beginners and powerful for advanced users  
- It has a large and active community  

## How to install VS Code

### Step 1: Visit the official website
Go to: [https://code.visualstudio.com/](https://code.visualstudio.com/)

### Step 2: Download the correct installer
Choose the download that matches your operating system:

- Windows  
- macOS  
- Linux  

### Step 3: Run the installer
Open the downloaded file and follow the setup steps on your screen.

- On Windows, you will click **Next** a few times and accept the agreement.  
- On macOS, you will drag **VS Code** into the **Applications** folder.  
- On Linux, you may install using a package manager or the provided installer.

### Step 4: Open VS Code
After installation, open VS Code. You should see a welcome screen that lets you:

- Open a folder  
- Open a file  
- Start a new file  

## Optional but helpful initial settings

- Enable automatic updates so you always have the latest features  
- Choose a theme you like so the editor is comfortable for your eyes  
- Install a file icon theme to make folders and file types clearer  

You can change these later in the **Settings** menu.

## Alternative editors

Although VS Code is the recommended choice, it is useful to know other editors exist:

- Sublime Text  
- Atom  
- JetBrains IDEs, such as WebStorm or PyCharm  

These are not required for this course. You can do everything you need with VS Code.
