# Essential Editor Features

Visual Studio Code has many features, but you do not need to learn everything at once. Focus on the core features that make your life easier as a beginner.

These core features include:

- Syntax highlighting  
- Extensions  
- Search and replace  
- The Command Palette  
- The integrated terminal  

## Syntax highlighting

Syntax highlighting uses colors to show different parts of your code. This makes it easier to read and understand.

For example:

- Keywords might appear in one color  
- Strings in another color  
- Comments in a softer color  
- Errors underlined or highlighted  

This visual feedback helps you spot mistakes quickly.

You can change the color theme in:

- **Settings**  
- Or by pressing **Ctrl + K**, then **Ctrl + T** in VS Code on Windows  
- Or **Command + K**, then **Command + T** on macOS  

## Extensions

Extensions allow you to add new features to VS Code. You can use them to:

- Format your code automatically  
- Add support for new languages  
- Improve Git integration  
- Preview HTML in the browser  
- Get smart suggestions and linting  

Some beginner-friendly extensions are:

- **Prettier** – for code formatting  
- **ESLint** – for JavaScript linting  
- **Live Server** – for previewing web pages  
- **GitLens** – for better version control visibility  

### How to install an extension

1. Open VS Code  
2. Click the **Extensions** icon on the left sidebar  
3. Type the extension name into the search bar  
4. Click **Install**  

## Search and replace

To search within a single file:

- Press **Ctrl + F** on Windows  
- Press **Command + F** on macOS  

To search across all files in your project:

- Press **Ctrl + Shift + F** on Windows  
- Press **Command + Shift + F** on macOS  

You can also replace text using the replace option in the search box.

## Command Palette

The Command Palette lets you run almost any action in VS Code by typing its name.

To open it:

- Press **Ctrl + Shift + P** on Windows  
- Press **Command + Shift + P** on macOS  

Then you can type actions like:

- Toggle terminal  
- Change color theme  
- Format document  

This helps you discover features without clicking through menus.

## Integrated terminal

VS Code includes a built-in terminal so you can run commands without leaving the editor.

To open the terminal:

- Press **Ctrl** + backtick ( ` ) on Windows  
- Press **Command** + backtick ( ` ) on macOS  

From this terminal, you can:

- Navigate folders  
- Run scripts  
- Use Git  
- Start development servers
