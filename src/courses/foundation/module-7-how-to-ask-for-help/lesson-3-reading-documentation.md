# Lesson 3: Reading Documentation and Official Resources

## The Big Idea

The most reliable source of information is **official documentation**.

It's written by the creators of the tool you're using. It's accurate, comprehensive, and updated regularly.

Learning to read documentation is a superpower that separates beginners from professionals.

## Why Documentation is Your Best Friend

### It's Authoritative

Written by the people who built it.

### It's Current

Updated as features change.

### It's Complete

Everything you need to know is there (if you know where to look).

### It's Free

No paywall, no ads, always available.

### It's Often Better Than Tutorials

Because it covers EVERYTHING, not just the basics.

## The Problem With Documentation

Here's the catch: **documentation is often confusing for beginners**.

It's written by experts for experts. It assumes you know more than you do.

But you can learn to read it.

## How to Find Official Documentation

### Search "[Tool Name] Official Documentation"

**Examples:**

- "Python official documentation"
- "JavaScript MDN documentation"
- "React official documentation"

### Use These Sites

- **MDN** (Mozilla Developer Network) - For web technologies
- **Python.org** - For Python
- **npm.js** - For JavaScript libraries
- **Official GitHub** - For open source projects
- **Dev.to** - For community guides

### Look for These Signs of Official Docs

✅ The URL contains "official" or is the main site
✅ It looks professional and organized
✅ It has version information
✅ It's updated regularly (check the date)
✅ It has clear sections and navigation

## How to Read Documentation

### Step 1: Find the Right Section

Documentation is usually organized by topic.

Look for sections like:

- "Getting Started" or "Introduction"
- "API Reference"
- "How-to Guides"
- "Examples"

**Example:** Looking for how to read a file in Python?

- Search: Python official docs → scroll to "File I/O"

### Step 2: Skim for Your Specific Need

Don't read every word. Look for:

- Headings that match what you want
- Code examples (usually bolded or in boxes)
- "See also" or "Related" sections

**Example:** You want to know how to sort a list

- Search: "sort" → Find the sort() method documentation → Read that section

### Step 3: Find the Code Example

Most documentation has code examples.

**Example from Python docs:**

```python
>>> a = [1, 2, 3, 4]
>>> a.sort()
>>> a
[1, 2, 3, 4]
```

### Step 4: Try It Yourself

Don't just read. Copy the example and run it.

See if it works the way the docs describe.

### Step 5: Adapt It to Your Problem

Take the example and change it to fit what you're doing.

**Example:**

- Documentation shows: `list.sort()`
- You need: Sort a list of numbers in reverse
- Find: The parameter `reverse=True`
- Adapt: `my_list.sort(reverse=True)`

## Common Documentation Sections

### API Reference

Lists every function/method and what it does.

**How to use it:**

1. Find your function name
2. Read the description
3. Look at "Parameters" to see what goes in
4. Look at "Returns" to see what comes out
5. Copy the example and try it

### How-to Guides

Step-by-step instructions for common tasks.

**How to use it:**

1. Find the task you want to do
2. Follow the steps
3. Try the code examples as you go

### Tutorial

Introduction for beginners.

**How to use it:**
Start here if you're completely new to something.

### FAQ (Frequently Asked Questions)

Common questions already answered.

**How to use it:**
Ctrl+F to search for your question.

## Real-World Documentation Reading

### Scenario: You want to format a date in Python

**Step 1:** Search "Python documentation date formatting"

**Step 2:** Find datetime module documentation

**Step 3:** Look for "strftime" method (formats dates as strings)

**Step 4:** Read the example:

```python
from datetime import datetime
now = datetime.now()
print(now.strftime("%Y-%m-%d"))
# Output: 2024-01-06
```

**Step 5:** Adapt to your problem:

- You want: "06/01/2024"
- Find the format code: "%m/%d/%Y"
- Your code: `now.strftime("%m/%d/%Y")`

Done! Solution found without asking anyone.

## Tips for Reading Confusing Documentation

### Tip 1: Use Ctrl+F to Search Within the Page

Find keywords relevant to your problem.

### Tip 2: Look for "Examples" Section

It's usually clearer than the description.

### Tip 3: Check the Version

Make sure the documentation matches your installed version.

### Tip 4: Read the Comments in Code

Often the example code has helpful comments.

### Tip 5: Check the "See Also" Section

Links to related documentation.

## When Documentation Isn't Enough

After reading documentation thoroughly:

- Try the examples provided
- Try to adapt them to your situation
- Search Stack Overflow for similar problems
- THEN ask for help

You've now shown you made a good-faith effort.

## Key Takeaway

**Official documentation is your most reliable resource.**

Reading it takes practice, but it's worth mastering.
