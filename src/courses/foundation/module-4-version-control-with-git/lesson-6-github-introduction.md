# Introduction to GitHub/GitLab

So far, all your git commands have been **Local**. They only live on your computer. If your hard drive crashes, your code is gone.

We need a **Remote** place to store our code.

## What is GitHub?

GitHub is a website that hosts Git repositories. It is:

1.  **Cloud Storage**: backup for your code.
2.  **Portfolio**: show off your work to employers.
3.  **Collaboration Hub**: work with developers around the world.

_Note: GitLab and Bitbucket are alternatives that do the same thing, but GitHub is the most popular._

## Local vs Remote

- **Local Repo**: The `.git` folder on your laptop. You work here.
- **Remote Repo**: The copy of your project on GitHub's servers. You "Push" your work here.

## Getting started

1. Go to [github.com](https://github.com)
2. Sign up for a free account.
3. Choose a username (professional is better!).
